# Flare Event Notifier

A tiny mod that notifies the player when a green exfil flare was used correctly.

### How to install

1. Download the latest release here: [link](https://github.com/SkebbZ/ExfilFlare/releases) -OR- build from source 
2. Simply extract the zip file contents into your root SPT folder (where EscapeFromTarkov.exe is)
3. Your `BepInEx/plugins` folder should now contain a `ExfilFlare.dll` file inside
